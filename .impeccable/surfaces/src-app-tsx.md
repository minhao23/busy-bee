# Busy Bee App

Mode: Operate. Targets: `src/App.tsx`, `src/components/Dashboard.tsx`, `src/components/TodoList.tsx`.

## Direction contract

THESIS: Tighten the existing Telegram-first focus app, preserving Pomodoro and the essential Eisenhower matrix. A compact working interface, not a marketing page or a stack of explanatory panels.

OWN-WORLD: Deep blue canvas, slate-blue work areas, warm sand selection in a 60-30-10 hierarchy. Self-hosted Satoshi with proper variable weights. Flat tonal depth, softly curved controls, four restrained semantic quadrant colors.

STORY: Review the four priorities, move a task, and begin focused work. Dragging has a touch handle and a tap/keyboard alternative. Database writes have pending, confirmed, and rollback states.

FIRST VIEWPORT: A compact brand/date header, a focused timer with session count, duration selection and large Start control. Tasks uses a short heading, add form and a two-by-two matrix even on phones. Navigation stays at the thumb edge below 760px; desktop gains a wider split view.

FORM: User-pinned calm-premium refinement of the existing blue identity, retaining core product structure. Code-led Operate build. No generated comp or randomized visual-world selection: the direction was selected by the user before the interrupted implementation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Verification

Browser evidence uses synthetic isolated task data, explicitly identified in the test results. No live task data is modified. Phone and desktop checks run at 320, 360, 390, 430, 768, and 1440px. Native Telegram iOS/Android WebViews remain a device verification gap.
